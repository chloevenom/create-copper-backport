# create-copper-backport
This resource pack backports the updated copper textures from Create 6 to Create 5.1, mainly for use by people who are playing modpacks that are still on Create 5.1 but would rather use the newer textures.

## Introduction
Have you ever thought to yourself while playing an older version of Create, "Man, these copper textures look so vibrant compared to the newer ones... Gosh, I wish there was a way to make these look **LESS VIBRANT** and in fact **MORE DULL**!"

..no?

Woops.

## Intended Use Case
This was made with the intention of being used in modpacks that are still using versions before Create 6, whether due to not being updated or a delibrate choice to omit Create 6 features for balancing, by authors or players of said modpack.

## Notice
This resource pack does not change any models, any textures made for models that were changed in the Create 6 update were altered to fit the models from Create 5.

The only "original" textures here are (so far) the boiler gauge and fluid valve, any other textures are either slightly altered to fit Create 5's models or are straight taken from Create 6. These textures were made by [simibubi](https://modrinth.com/user/simibubi) and are theirs first.
